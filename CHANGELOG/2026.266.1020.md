# 2026.266.1020 — feat: relocate the gpu R10 witness bed from opencharly/charly

## Summary of changes

Relocate the `check-gpu-local` R10 witness bed (and its `check-gpu-app` `kind:local` template) from `opencharly/charly` into `opencharly/plugin-gpu`, the repo that owns the `candy/plugin-gpu` provider it exercises. A bed must live in the repo that owns what it tests: the check-bed runner's dev-tree override maps the bed PROJECT's own superproject's `@github` refs at the local tree, so a plugin candy owned by another repo was never exercised as in-development code while its witness sat in core. Relocated here, the template composes the LOCAL plugin candy with no `@github` pin. Additive config (the repo previously declared no entities of its own) plus the CI pin bump and a generated-artifact `.gitignore`.

- `charly.yml` (+41/−2) — adds the `check-gpu-app` `kind:local` template (composing the LOCAL `plugin-gpu` candy) and the `check-gpu-local` bed (`disposable: true`, `host: local`, two runtime GPU checks); migrates the `version:` stamp `2026.232.0520` → `2026.249.2125`; sweeps the now-false "declares no entities of its own" header comment.
- `.github/workflows/deploy.yml` (+1/−1) — bumps the pinned charly source `v2026.238.1242` → `v2026.256.1316` against the same `opencharly/charly` URL, so the CI `charly box validate` step runs on a binary at/after the migration stamp.
- `.gitignore` (+16/−0, new file) — the standard generated-artifact ignores (`.build/`, `.containerignore`, `.dockerignore`, `.check/`, `output/`, editor swaps, `*.bak`/`*.bak.*` migration backups).
